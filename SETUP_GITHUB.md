# GitHub Setup Instructions

After creating your repository on GitHub, run these commands:

```bash
# Add your GitHub repository as remote (replace YOUR_USERNAME with your GitHub username)
git remote add origin https://github.com/YOUR_USERNAME/sbgn-visualization-demo.git

# Push to GitHub
git branch -M main
git push -u origin main
```

Or if you prefer SSH:

```bash
git remote add origin git@github.com:YOUR_USERNAME/sbgn-visualization-demo.git
git branch -M main
git push -u origin main
```
